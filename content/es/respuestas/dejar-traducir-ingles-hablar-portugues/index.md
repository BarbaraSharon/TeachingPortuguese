## Traducir es una etapa, no un fracaso

Los principiantes utilizan de forma natural una lengua conocida para comprender otra. El problema aparece cuando cada respuesta exige construir una frase inglesa completa y convertir palabra por palabra. El orden, los verbos y las expresiones del portugués no siempre coinciden, por lo que el proceso se vuelve lento y poco fiable.

## Crea conexiones directas

- Relaciona **objetos y acciones** con palabras portuguesas sin nombrarlos primero en inglés.
- Aprende **expresiones completas** para opinar, pedir aclaraciones o ganar tiempo.
- Contesta **la misma pregunta de varias maneras** en lugar de memorizar un único guion.
- Describe una imagen o actividad cotidiana usando solo el portugués que ya tienes.
- Cuenta una historia breve a partir de palabras clave, no de un texto inglés.

Empieza con tareas breves. La velocidad no es el primer objetivo; lo es recuperar el lenguaje de forma fiable. Después cambia un detalle y utiliza la respuesta en una conversación menos previsible.

## Utiliza el inglés con intención

El inglés puede ayudar a comparar gramática o confirmar un significado importante. Úsalo como herramienta y vuelve después a ejemplos portugueses. Evita redactar un guion inglés para cada conversación, porque eso practica la traducción más que el habla espontánea.
